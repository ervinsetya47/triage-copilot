🛡️ Bug Bounty Triage Copilot

Check a finding before you pay the submission fee: scope, known issues, public disclosures, severity — one verdict, and a report draft if the finding is alive. Deterministic, rule-based, no LLM, no network. A dead finding is a saved fee. Built with Kiro for Kiroween 2026. The copilot never auto-submits anything.
