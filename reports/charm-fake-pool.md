# Fake Uniswap V3 pool drains Alpha Vault via unchecked createVault pool and mint callback

**Program:** Charm  
**Target:** AlphaProVaultFactory / AlphaProVault  
**Severity:** Critical-class  
**Verdict:** REPORTABLE (triage copilot)

## Description

AlphaProVaultFactory.createVault() never validates params.pool, so an attacker can register a fake Uniswap V3 pool. uniswapV3MintCallback only checks msg.sender == address(pool) and then safeTransfers whatever amounts the pool requests. Attack: deploy EvilPool, call createVault(pool=EvilPool), victims deposit into the officially registered vault, then the manager calls rebalance() and the fake pool's callback drains the vault. Vault went from 1000 TK0 + 1000 TK1 to 0 + 0; the fake pool received 1000 TK0 + 1000 TK1 via real ERC20 transfers.
