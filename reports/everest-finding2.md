## Finding summary (for the record)

AnchorStateRegistry / OptimismPortal2: setRespectedGameType cannot stop in-flight games from anchoring. A game created while type A was respected still anchors after the Guardian switches the respected game type to type B, so a withdrawal proven against the old game can still be finalized. This is documented intended design: the OP Stack spec provides in-flight withdrawal safety, the repo's own test asserts a withdrawal is still finalizable after the switch, and the OptimismPortal2 NatSpec says retirement — not a type switch — is the blanket invalidation. It was also publicly reported as Informational in Cantina Optimism Upgrade 19 section 3.3.1 (ASR cutovers leave old games valid).

**PoC notes:** PoC passed 4/4 on the local Everest devnet: game created under type A anchored and its withdrawal finalized after the Guardian switched the respected game type to type B.
