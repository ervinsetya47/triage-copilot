# _pullOrderFunds takes the order address's entire Hub balance with no signed amountIn

**Program:** Relay  
**Target:** RelayExecutor._pullOrderFunds  
**Severity:** S3/L2 (High-class)  
**Verdict:** REPORTABLE (triage copilot)

## Description

Relay settlement: RelayExecutor._pullOrderFunds takes the order address's ENTIRE Hub balance with no signed amountIn, so a malicious executor can pull more than the order authorized. The attacker sweeps the surplus to itself: the order was funded with 1000 tokenIn and the attacker swept +900 tokenIn beyond the order amount. RelayInbox MINT tops up the same order address across deposits, and refund residue left in the order address is re-pullable. Assessed S3/L2, approximately $15,000.
